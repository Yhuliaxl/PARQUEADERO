📋 Descripción General

El proyecto consiste en el desarrollo de una plataforma web para la administración integral de parqueaderos, diseñada para centralizar, automatizar y optimizar el control de todas las operaciones realizadas dentro del establecimiento.

La aplicación permitirá gestionar:

 ✅ Clientes
 ✅ Vehículos
 ✅ Ingresos y salidas
 ✅ Mensualidades
 ✅ Tarifas configurables
 ✅ Pagos
 ✅ Almacén de pertenencias
 ✅ Gastos operativos
 ✅ Reportes administrativos
 ✅ Estadísticas y gráficos
 ✅ Usuarios y permisos

El objetivo es reducir procesos manuales, mejorar la organización del negocio y proporcionar información financiera y operativa en tiempo real.

🎯 Objetivos del Proyecto
Automatizar el registro de ingresos y salidas.
Gestionar vehículos y clientes de manera centralizada.
Administrar mensualidades y sus renovaciones.
Configurar tarifas según las necesidades del negocio.
Mantener control sobre pagos e ingresos.
Gestionar gastos operativos.
Generar reportes y estadísticas.
Facilitar la toma de decisiones mediante información histórica y trazable.
